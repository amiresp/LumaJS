# LumaJS

A zero-build, dependency-free, backend-agnostic JavaScript frontend runtime.

> Initial repository bootstrap. The runtime implementation is proposed through pull requests.

LumaJS targets browsers with native ES module support. Node.js is optional; static hosting, ASP.NET, PHP and other HTTP servers can serve the same frontend files.

See the first implementation pull request for architecture, component contracts, Story, Slider and a runnable example.
